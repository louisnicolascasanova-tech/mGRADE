DISCUSSION SUMMARY: CLEANING AND TRACKING IMPLEMENTATION
=========================================================
Date: 2025-07-31
Context: Debugging IMDB training collapse around epochs 20-40

PROBLEM IDENTIFIED:
- IMDB experiments (yaml_folder/imdb_*) collapse between epochs 20-40
- Validation accuracy drops to ~0.50 (random chance) suddenly
- Need comprehensive monitoring to identify root cause

SOLUTIONS IMPLEMENTED:
======================

1. GRADIENT MONITORING & CLIPPING
---------------------------------
Files Modified: training.py, main.py

Added gradient tracking:
- Global gradient norm: train/grad_norm, train/grad_norm_log
- Pre/post clipping norms: train/grad_norm_post_clip  
- Clipping indicator: train/grad_clipped (0/1)
- Per-layer gradient norms: grad_norm/{layer}
- Per-layer gradient variance: grad_variance/{layer}
- Gradient histograms: train/gradients/{layer} (optional)

Gradient clipping implementation:
- Default clip norm: 1.0 (configurable via grad_clip_norm in YAML)
- Uses optax.clip_by_global_norm()
- Logs whether clipping occurred at each step

Learning rate monitoring:
- train/learning_rate tracks current LR schedule

2. MODEL BEHAVIOR METRICS
-------------------------
Files Modified: training.py (apply_model, run_epoch, validate functions)

Prediction confidence tracking:
- train/mean_confidence: Average max softmax probability per batch
- train/confidence_std: Standard deviation of max probabilities
- Per-epoch aggregation: train/mean_confidence, train/confidence_std

Class distribution analysis:
- train/pred_class_{i}_ratio: Prediction distribution per class
- train/target_class_{i}_ratio: True label distribution per class
- Helps identify model bias and class collapse

Classification reports (sklearn):
- Per-class metrics: train/precision_class_{i}, train/recall_class_{i}, train/f1_class_{i}
- Macro averages: train/macro_avg_precision, train/macro_avg_recall, train/macro_avg_f1
- Weighted averages: train/weighted_avg_precision, train/weighted_avg_recall, train/weighted_avg_f1
- Visual confusion matrix: train/confusion_matrix (wandb image)

3. VALIDATION & TEST TRACKING  
------------------------------
Files Modified: training.py (validate, eval_model), main.py

Enhanced validation function:
- Returns metrics instead of logging separately (fixes wandb step ordering)
- Collects predictions across all validation batches

Validation metrics (val/ section):
- val/loss, val/acc, val/loss_best, val/acc_best

Test metrics (test/ section):
